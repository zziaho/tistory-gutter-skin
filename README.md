## Why Gutter?

개발 블로그의 본문은 절반이 코드입니다. 그런데 대부분의 티스토리 스킨은 코드블록을
회색 박스 하나로 처리합니다. 줄 번호가 없어 "12번째 줄 보세요"라고 쓸 수 없고,
있더라도 복사하면 번호가 같이 딸려옵니다.

Gutter 는 그 지점만 집요하게 봅니다.

- **거터를 `<pre>` 바깥에 둡니다.** 그래서 복사에 번호가 섞이지 않고, 가로
  스크롤을 해도 제자리에 남습니다.
- **문법 강조 색을 사이트 색으로 승격했습니다.** 카테고리는 keyword 보라, 링크는
  function 파랑. 글 전체가 에디터와 같은 색 규칙으로 읽힙니다.

IDE 크롬(탭바·파일트리·상태바)은 일부러 그리지 않습니다. 흉내로 읽히는 데다
모바일에서 전부 버려야 해서 데스크톱과 인상이 갈리기 때문입니다.

## Features

**코드블록** — 언어 배지, 복사 버튼, 좌측 테두리 색 23개 언어.
언어를 지정한 블록만 칠합니다. 자동 감지는 평문에 엉뚱한 키워드 색을 칠하므로
쓰지 않고, 언어 없는 블록은 배지·복사·거터 없이 그냥 둡니다.

**highlight.js 를 필요할 때만 받습니다.** 코드블록을 찾은 뒤에, 그 글에 실제로
쓰인 언어만. 홈·목록·카테고리·검색·방명록은 코어조차 받지 않습니다.

**에디터 두 방식이 같은 모양으로 나옵니다.** 티스토리 기본 에디터와 마크다운
모드는 같은 글도 다른 HTML 로 내보냅니다. 문단 여백(`data-ke-size`), 코드블록
언어(`data-ke-language` vs `class="language-*"`), 인용문(`data-ke-style`) 세
군데가 갈리는데 양쪽을 맞춰뒀습니다.

**자동 목차.** H2/H3 를 읽어 만들고 IntersectionObserver 로 현재 섹션을
표시합니다. 좁은 화면에서는 본문 위 접이식 상자가 되고 접힌 채로 시작합니다.

**다크모드.** OS 설정 감지 + 수동 토글 + `localStorage` 저장. 렌더 전 인라인
스크립트가 클래스를 붙여 깜빡임이 없습니다.

**색 대비 WCAG AA.** 본문·메타·문법 강조 토큰 전부 배경 대비 4.5:1 이상.
라이트·다크 양쪽에서 검증했습니다.

**모바일까지 PC 스킨 하나로.** 1180 / 900 / 768px 세 단계 반응형이라 티스토리
모바일 스킨이 필요하지 않습니다. 대신 '모바일 웹 자동 연결' 을 꺼야 합니다
([Install](#install) 3번).

### 그 밖에

읽기 진행률 바 · 읽는 시간과 글자수 · 헤딩 앵커 · 이미지 라이트박스 ·

## Install

> 전체 절차·옵션 설명·문제 해결은
> **[설정 · 커스터마이징 안내](docs/SETUP.md)** 가 정본입니다. 아래는 요약입니다.

**1. 내려받기** — [Releases](https://github.com/zziaho/tistory-gutter-skin/releases)
또는 `git clone https://github.com/zziaho/tistory-gutter-skin.git`

**2. 올리기** — `블로그 관리 > 꾸미기 > 스킨 등록`

| 파일 | 올릴 위치 |
|------|-----------|
| `index.xml`, `skin.html`, `style.css`, `preview*` | 루트 |
| `script.js` | **`images/` 아래** |

`script.js` 의 경로가 중요합니다. `skin.html` 이 `./images/script.js` 로
참조하고, 티스토리는 필수 3개 파일 외에는 `images/` 아래만 받습니다.

**3. 관리자 설정** — 스킨 파일만 올려서는 부족합니다

| 설정 | 안 하면 |
|------|---------|
| `꾸미기 > 모바일` 의 **모바일 웹 자동 연결 끄기** | **모바일 방문자가 이 스킨을 못 봅니다.** 티스토리 기본 모바일 스킨이 뜹니다 |
| `메뉴 > 카테고리 관리` 를 **리스트형**으로 | 카테고리가 `table`+`gif` 로 나와 스타일도 크롤링도 안 됩니다 |

**4. 광고 (선택)** — 게시자 ID 는 하드코딩되어 있지 않습니다. 스킨 설정에
`애드센스 게시자 ID` 와 슬롯 ID 를 채우면 켜지고, 비우면 스크립트 자체가
출력되지 않습니다.

## Customize

**스킨 옵션 12개** — 색 2, 표시 5, 구조화 데이터 2, 광고 3. HTML·CSS 를 고치지
않고 관리자에서 바꿉니다. → [옵션 전체 설명](docs/SETUP.md#3-스킨-옵션)

**CSS 커스텀 프로퍼티** — 그 이상은 `style.css` 맨 위 `:root` 를 고칩니다.
표면·글자·문법 강조 색, `--radius`, `--measure`, 글꼴이 모여 있습니다.
같은 이름의 토큰이 `html.dark` 에 한 벌 더 있으니 같이 고쳐야 합니다.
→ [토큰 표](docs/SETUP.md#6-색-바꾸기)

색을 바꿀 때는 **배경 대비 4.5:1** 을 넘기세요. 기본값은 Atom One Light 원색이
아니라 본문·코드 배경 양쪽에서 그 기준을 넘도록 명도를 낮춰 잡은 값입니다.

두 곳은 의도적으로 옵션을 따르지 않습니다. **코드블록 안의 색** — 사이트 색을
문법 팔레트에서 가져오는 방향이지 반대가 아니고, 옵션을 밝게 바꿨을 때 코드가
안 읽히는 일을 막습니다. **다크모드** — 라이트 기준으로 고른 색이 어두운
배경에서 대비가 무너지는 일이 잦아 별도 팔레트를 씁니다.

## How it works

```
skin/
├── index.xml          # 스킨 정보 + 스킨 옵션 12개
├── skin.html          # 전 페이지 공용 템플릿
├── style.css          # 전체 스타일시트
├── preview*.jpg|gif   # 관리자 화면용. 파일명·크기가 플랫폼 규약
└── images/script.js   # 12개 모듈, 의존성 0
```

`skin.html` **하나가** 홈·목록·글·카테고리·검색·태그·방명록을 전부 렌더링합니다.
페이지별로 파일이 나뉘지 않고 URL 에 따라 치환자 블록이 켜지고 꺼집니다.

레이아웃은 `<html>` 의 클래스 두 개(`is-post`, `has-toc`)로 갈립니다. 둘 다
퍼머링크 블록 안의 인라인 스크립트가 붙이므로 첫 페인트 전에 결정됩니다.

빌드 과정이 없습니다. `skin/` 아래 파일을 고치면 그대로 동작하고, 확인은
스킨 등록으로 올려 실제 블로그에서 합니다. CSS 는 커스텀 프로퍼티, JS 는
Vanilla ES5 IIFE, 레이아웃은 CSS Grid 입니다.

치환자 구조와 `h1` 판별 규칙은 [부록](docs/SETUP.md#부록-스킨-구조)에 있습니다.

## Known Limitations

- **highlight.js CDN 의존.** cdnjs 장애 시 코드블록이 무채색으로 떨어집니다.

- **광고 미충전 시 레이아웃 이동(CLS).** 애드센스는 채워지지 않은 유닛에
  `display:none` 을 겁니다. CSS 로 잡아 둔 크기가 그 순간 무의미해져 자리가 0 이
  되고 아래 내용이 위로 올라옵니다. 실측(2026-08-31) 데스크톱 CLS 0.075 /
  모바일 0.166 의 대부분이 이 이동입니다. 바깥 래퍼에 `min-height` 를 걸어
  붙잡아 봤지만 이동이 오히려 늘어(모바일 0.326) 채택하지 않았습니다. 본문
  블록이 늦게 나타나는 별도 원인은 티스토리가 `.post-content` 에 인라인 높이를
  넣는 쪽이라 스킨에서 손댈 수 없습니다.

- **검증 범위.** 1.0.0 은 블로그 한 곳에서 검증했습니다. 다른 블로그의 글
  마크업·플러그인·카테고리 구조에서 겹치는 문제가 있을 수 있습니다.

## Contributing

**문제를 발견하면 [Issues](https://github.com/zziaho/tistory-gutter-skin/issues) 에 올려주세요.**
직접 쓰다 막힌 지점이 가장 값어치 있는 제보입니다.

티스토리 스킨은 페이지 종류마다 다른 치환자 블록이 켜지고 꺼집니다. 그래서
**어느 페이지인지가 원인 절반을 알려줍니다.** 아래가 함께 있으면 훨씬 빨리
좁힐 수 있습니다.

- 문제가 보이는 **글 주소**, 그리고 목록·글·카테고리·검색·태그·방명록 중 어디인지
- 브라우저와 기기 (예: Chrome 141 / Windows, Safari / iPhone)
- 라이트 / 다크 중 어느 쪽인지, 스킨 옵션에서 바꾼 값
- 스크린샷

기능 제안, 다른 블로그에서 겹치는 스타일 충돌, 문서에서 틀린 서술도 환영합니다.
Pull Request 도 받습니다.
