# Gutter

개발 블로그를 위한 티스토리 스킨. 코드블록에 IDE 라인 넘버 거터를 달고,
문법 강조 팔레트를 사이트 UI 색으로 그대로 씁니다.

> **상태: 0.1.0 — 실제 블로그에서 동작 중입니다.**
> 아직 초기 버전이라 미구현 영역이 있습니다.
> 아래 [알려진 제약](#알려진-제약)을 먼저 읽어주세요.

---

## 특징

**코드블록 라인 넘버 거터**
`<pre>` 바깥의 독립 요소입니다. 복사할 때 줄 번호가 딸려오지 않고,
가로 스크롤을 해도 거터는 제자리에 남습니다.

**문법 강조 색을 UI 색으로**
카테고리는 keyword 보라, 링크는 function 파랑, 메타 정보는 comment 회색.
기본값은 Atom One Light 팔레트이며 스킨 옵션에서 바꿀 수 있습니다.

**IDE 크롬은 그리지 않습니다**
탭바·파일트리·상태바를 흉내 내지 않습니다. 흉내로 읽히는 데다,
모바일에서 전부 버려야 해서 데스크톱과 인상이 갈리기 때문입니다.
정체성은 모노스페이스 메타 표기와 색 체계 두 곳에만 둡니다.

**그 밖에**
다크모드(FOUC 없음) · 글 상세 좌측 목차 + 스크롤 추적 · 읽기 진행률 바 ·
코드 복사 버튼 · 검색 오버레이 · 이미지 라이트박스 · 읽는 시간 ·
작성자 귀속 JSON-LD

## 설치

`관리 > 꾸미기 > 스킨 등록` 에서 `skin/` 아래 네 파일을 모두 올린 뒤 적용합니다.

```
skin/
├── index.xml       스킨 정보 + 스킨 옵션 11개
├── skin.html       전 페이지 공용 템플릿
├── style.css
└── images/
    └── script.js
```

`index.xml` 은 스킨 편집기에서 수정할 수 없습니다. 옵션 **선언**을 바꾸려면
등록 경로로 다시 올려야 합니다. 옵션 **값**은 스킨 편집기 UI 에서 바꿉니다.

### 애드센스

게시자 ID 는 하드코딩돼 있지 않습니다. 광고를 넣으려면 스킨 옵션에서
`애드센스 게시자 ID`(`ca-pub-...`)와 `본문 광고 슬롯 ID` 를 채우세요.
비워두면 광고 스크립트 자체가 출력되지 않습니다.

## 스킨 옵션

| 옵션 | 타입 | 기본값 |
|---|---|---|
| 강조 색상 (카테고리) | COLOR | `#a626a4` |
| 링크 색상 | COLOR | `#4078f2` |
| 코드블록 라인 넘버 | BOOL | `true` |
| 기본 다크모드 여부 | BOOL | `false` |
| 목차 표시 | BOOL | `true` |
| 카테고리 표시 | BOOL | `true` |
| 블로그 부제 | STRING | 개발과 일상을 기록합니다 |
| 작성자 이름 | STRING | ZIAHO |
| 작성자 프로필 주소 | STRING | (없음) |
| 애드센스 게시자 ID | STRING | (없음) |
| 애드센스 본문 광고 슬롯 ID | STRING | (없음) |

다크모드에서는 강조·링크 색상 옵션을 쓰지 않습니다. 라이트 배경 기준으로 고른
색이라 어두운 배경에서 대비가 무너지기 때문입니다.

## 알려진 제약

- **댓글·방명록이 없습니다.** `s_rp`, `s_rp_rep`, `s_rp_input_form`, `s_guest`
  블록을 아직 넣지 않았습니다. 푸터의 guestbook 링크는 빈 페이지로 이어집니다.
- **미리보기 이미지가 없습니다.** `preview.gif`(112x84), `preview256.jpg`,
  `preview560.jpg`, `preview1600.jpg`. 없어도 등록·적용은 되지만
  스킨 목록에서 썸네일이 비어 보입니다.
- **`<default>` 섹션이 없습니다.** `recentEntries`, `contentWidth`,
  요약 말줄임 길이 등이 전부 플랫폼 기본값으로 동작합니다.
- **경로형 브레드크럼 미구현.** 카테고리를 `~/backend/jpa/08-proxy` 같은
  경로 표기로 보여주려던 설계였으나, 현재는 카테고리명을 그대로 출력합니다.
- **highlight.js CDN 의존.** cdnjs 장애 시 코드블록이 무채색으로 떨어집니다.

## 개발

`skin.html` 하나가 홈·목록·글·카테고리·검색·태그를 전부 렌더링합니다.
페이지 종류별로 파일이 나뉘지 않고, URL 에 따라 그룹 치환자 블록이 켜지고 꺼집니다.

글 상세 3단 레이아웃은 퍼머링크 블록 안의 인라인 스크립트가
`<html class="is-post">` 를 붙여 판별합니다.

`index.xml` 은 스킨 편집기에서 열리지 않습니다. 옵션 **선언**을 바꿨다면
`관리 > 꾸미기 > 스킨 등록` 으로 네 파일을 다시 올려야 반영됩니다.
