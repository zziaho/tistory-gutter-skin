# Gutter 설정 · 커스터마이징 안내

스킨을 올린 뒤 실제로 쓰기까지 필요한 것을 순서대로 정리했습니다.
개요와 기능 소개는 [README](../README.md) 에 있습니다.

**먼저 읽을 것** — 스킨 파일만 올려서는 부족합니다. 티스토리 관리자 쪽 설정
세 가지를 같이 해야 의도대로 동작합니다. [2. 티스토리 설정](#2-티스토리-설정)
이 그 절입니다. 특히 **모바일 웹 자동 연결**을 끄지 않으면 모바일 방문자는
이 스킨을 아예 보지 못합니다.

## 1. 스킨 등록

### 백업 먼저

`블로그 관리 > 꾸미기 > 스킨 편집 > html 편집` 에서 `skin.html` 과 `style.css`
내용을 복사해 따로 저장해 두세요. 덮어쓰면 이전 내용을 되찾기 어렵습니다.

### 파일 올리기

`블로그 관리 > 꾸미기 > 스킨 등록` 에서 `skin/` 아래 파일을 올립니다.

| 파일 | 올릴 위치 |
|------|-----------|
| `index.xml` | 루트 |
| `skin.html` | 루트 |
| `style.css` | 루트 |
| `preview.gif`, `preview256.jpg`, `preview560.jpg`, `preview1600.jpg` | 루트 |
| `images/script.js` | **`images/` 아래** |

`script.js` 의 경로가 중요합니다. `skin.html` 이 `./images/script.js` 로
참조하고, 티스토리는 필수 3개 파일 외에는 `images/` 아래만 받습니다.

### 나중에 수정할 때

- `skin.html` · `style.css` 만 고칠 때는 `스킨 편집 > html 편집` 에서 바로
  고쳐도 됩니다.
- **`index.xml` 은 스킨 편집기에서 열리지 않습니다.** 옵션을 추가하거나
  이름을 바꿨다면 `스킨 등록` 경로로 다시 올려야 합니다.
- **`index.xml` 을 다시 올려도 이미 저장된 옵션 값은 바뀌지 않습니다.**
  `<default>` 는 스킨을 처음 적용할 때만 쓰입니다. 기본값을 바꾼 뒤 그 값을
  쓰고 싶다면 `스킨 설정` 에서 손으로 바꿔야 합니다.

## 2. 티스토리 설정

스킨 파일과 별개로 관리자에서 해야 하는 것들입니다. 안 하면 기능이 조용히
동작하지 않습니다.

### 2-1. 모바일 웹 자동 연결 끄기 (필수)

`블로그 관리 > 꾸미기 > 모바일` 에서 **모바일 웹 자동 연결을 사용하지 않음**
으로 바꿉니다.

켜져 있으면 모바일에서 접속했을 때 `/m/` 주소로 넘어가고 **티스토리 기본
모바일 스킨**이 뜹니다. 이 스킨이 아니라 다른 페이지가 나온다는 뜻입니다.

Gutter 는 `@media (max-width: 1180px / 900px / 768px)` 분기를 갖춘 반응형이라
PC 스킨 하나로 모바일까지 처리합니다.

같은 글을 두 스킨으로 각각 측정한 결과입니다 (Lighthouse, 모바일 프리셋,
2026-08-31):

| | 티스토리 기본 모바일 스킨 | Gutter |
|---|---|---|
| 접근성 | 79 | **100** |
| CLS | 0.734 | 0.166 |
| LCP | 17.4s | 4.4s |

### 2-2. 카테고리 형식을 리스트형으로

카테고리 모듈의 표시 형식이 **폴더형이면 스타일이 먹지 않습니다.** 폴더형은
`table` + `gif` + `onclick` 마크업이라 진짜 `<a href>` 링크가 아니고, 그래서
검색엔진도 따라가지 못합니다. 리스트형으로 두세요.

### 2-3. 카테고리 글 수 표시

`index.xml` 의 `<default><tree><showValue>1</showValue>` 가 이 값을 켭니다.
카테고리 옆 `(N)` 이 안 보이면 관리자 쪽 카테고리 모듈 설정을 확인하세요.

`script.js` 의 `initCategoryCount` 가 그 숫자를 읽어 글 하단 경로에
`(N files)` 로 다시 씁니다. 숫자가 없으면 이 표시도 함께 사라집니다.

### 2-4. 블로그 설명 채우기 (권장)

`블로그 관리 > 블로그` 의 **블로그 설명**이 비어 있으면 티스토리가 홈에
`<meta name="description" content="">` 를 **빈 값으로** 내보냅니다.
검색 노출에 손해입니다. 글 페이지는 티스토리가 본문에서 자동으로 만들어
채우므로 홈만 해당됩니다.

### 2-5. '카테고리의 다른 글' (선택)

`블로그 관리 > 콘텐츠 > 설정` 의 '카테고리의 다른 글' 표시입니다. 켜면
티스토리가 본문 끝에 같은 카테고리 글 목록을 넣어 줍니다. Gutter 는 이 블록에
스타일을 맞춰 뒀습니다(`style.css` 의 `.another_category`).

내부 링크가 생기므로 켜 두는 쪽을 권합니다. 끄면 글 사이를 잇는 링크가
사라집니다.

## 3. 스킨 옵션

`블로그 관리 > 꾸미기 > 스킨 편집 > 스킨 설정` 에서 12개를 조정합니다.
HTML·CSS 를 고치지 않고 바꿀 수 있는 것들입니다.

### 색

| 옵션 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `accent` | COLOR | `#a626a4` | 카테고리·경로에 쓰는 강조 색 |
| `link_color` | COLOR | `#2364f0` | 본문 링크·활성 항목 색 |

바꿀 때는 **흰 배경에서 대비 4.5:1 을 넘는지** 확인하세요. 기본값은 둘 다
넘도록 골라 둔 값입니다 (각 5.86 / 4.84).

두 옵션은 **라이트 모드에서만** 쓰입니다. 다크 모드는 별도 팔레트를 씁니다 —
라이트 배경 기준으로 고른 색이 어두운 배경에서 대비가 무너지는 일이 잦기
때문입니다. 코드블록 안의 색도 이 옵션을 따르지 않습니다. 옵션을 밝은 색으로
바꿨을 때 코드가 안 읽히는 일을 막기 위해서입니다.

### 표시

| 옵션 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `line_numbers` | BOOL | `true` | 코드블록 왼쪽 라인 넘버 거터 |
| `dark_mode_default` | BOOL | `false` | 첫 방문 시 다크 모드로 시작 |
| `show_toc` | BOOL | `true` | 글 상세 좌측 목차 |
| `show_categories` | BOOL | `true` | 우측 카테고리 목록 (1180px 이하에서는 자동으로 숨김) |
| `subtitle` | STRING | 개발과 일상을 기록합니다 | 블로그 부제 |

`dark_mode_default` 는 **첫 방문 기본값**입니다. 방문자가 헤더의 토글로 바꾸면
그 선택을 `localStorage` (`gutter-theme`) 에 저장하므로 다음 방문에도 유지되고,
이 옵션보다 우선합니다.

### 구조화 데이터

| 옵션 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `author_name` | STRING | (빈값) | 검색엔진에 넘길 작성자 이름 |
| `author_url` | STRING | (빈값) | 작성자 프로필 주소 (GitHub 등) |

비워 두면 `author` 항목 자체를 넣지 않습니다. 빈 이름을 넣는 것보다 낫습니다.

### 광고

| 옵션 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `adsense_client` | STRING | (빈값) | 게시자 ID (`ca-pub-...`) |
| `adsense_slot` | STRING | (빈값) | 본문 **위** 광고 슬롯 ID |
| `adsense_slot_bottom` | STRING | (빈값) | 본문 **아래** 광고 슬롯 ID |

**게시자 ID 는 스킨에 하드코딩돼 있지 않습니다.** 비워 두면 애드센스 스크립트
자체가 출력되지 않습니다.

슬롯을 위·아래로 나눠 둔 이유는 한쪽만 켤 수 있게 하려는 것과, 애드센스에서
자리별 성과를 갈라 보기 위해서입니다. 슬롯 ID 를 비우면 그쪽 블록은 아예
출력되지 않습니다.

아래 유닛은 태그·이전다음글 **위**에 들어갑니다. 더 아래에 두면 티스토리가
주입하는 '카테고리의 다른 글' 과 겹쳐 문서 끝이 광고 두 덩어리가 됩니다.

> **알아둘 것 — 광고가 안 채워지면 자리가 무너집니다.**
> 광고 자리는 CSS 로 크기를 잡아 두지만(데스크톱 336x280 / 모바일 300x250),
> 애드센스는 채워지지 않은 유닛에 `display:none` 을 겁니다. 그 순간 잡아 둔
> 크기가 무의미해져 아래 내용이 위로 올라옵니다. 스킨에서 막을 방법을 찾지
> 못했습니다. 자세한 경위는 README 의 Known Limitations 에 있습니다.

## 4. 목차(TOC)

`show_toc` 를 켜면 글 상세 좌측에 목차가 붙습니다.

**본문의 `h2` · `h3` 를 읽어 자동으로 만듭니다.** 따로 표시할 것은 없습니다.
다만 조건이 있습니다:

- `h2`/`h3` 가 **2개 이상**이어야 만들어집니다. 그보다 적으면 목차를 넣지
  않습니다. 항목 하나짜리 목차는 쓸모가 없기 때문입니다.
- 제목에 자동으로 앵커(`#`)가 붙습니다. 제목에 마우스를 올리면 나타납니다.

### 화면 폭에 따라 달라집니다

| 폭 | 목차 위치 |
|---|---|
| 1180px 초과 | 본문 왼쪽 사이드바 (읽는 동안 따라옴) |
| 900 ~ 1180px | 왼쪽 사이드바 유지 (폭 200px 로 좁아짐) |
| 900px 이하 | 본문 **위** 접이식 상자. **접힌 상태로 시작** |

좁은 화면에서 펼친 채로 두면 긴 글에서는 목차만 1000px 가까이 되어 제목까지
스크롤해야 합니다. 그래서 접고 시작하고, `OUTLINE` 라벨을 누르면 펴집니다.
키보드로도 됩니다 (Tab 으로 이동 후 Enter 또는 Space).

## 5. 코드블록

티스토리 에디터에서 코드블록의 언어를 지정하면 그대로 인식합니다.
`js`, `py`, `kt`, `c++` 같은 별칭도 정규화됩니다. 마크다운 모드의 코드 펜스
뒤에 적은 언어도 동일하게 인식합니다.

색(좌측 테두리)이 지정된 언어는 23개입니다:

```
java  kotlin  javascript  typescript  python  go      sql     bash
html  css     scss        vue         json    yaml    xml     markdown
cpp   csharp  php         ruby        swift   rust    dart
```

나머지 언어는 문법 강조는 되지만 좌측 테두리가 회색으로 떨어집니다.
`powershell` 이 그렇습니다 — highlight.js 기본 번들에 없어 모듈을 따로
불러오므로 강조는 되지만 위 목록에는 없습니다.

**highlight.js 는 필요할 때만 받습니다.** 코드블록이 있는 글에서, 그 글에
실제로 쓰인 언어만 내려받습니다. 홈·목록·카테고리·검색·방명록에서는 코어조차
받지 않습니다.

라인 넘버는 `line_numbers` 옵션으로 끕니다. 거터가 `pre` 바깥에 있어서
**복사 버튼으로 복사할 때 줄 번호는 따라가지 않습니다.**

## 6. 색 바꾸기

스킨 옵션으로는 강조색과 링크색 두 개만 바뀝니다. 그 이상은 `style.css` 의
CSS 커스텀 프로퍼티를 고칩니다. 파일 맨 위 `:root` 블록에 모여 있습니다.

### 표면 · 글자

| 토큰 | 기본값 | 쓰이는 곳 |
|------|--------|-----------|
| `--bg` | `#fbfaf7` | 페이지 바탕 |
| `--surface` | `#ffffff` | 카드·헤더·푸터 |
| `--line` | `#f1efe8` | 옅은 구분선 |
| `--line-strong` | `#eae7dd` | 진한 구분선 |
| `--fg` | `#1b1c21` | 제목 |
| `--fg-body` | `#33353b` | 본문 |
| `--fg-muted` | `#6b6960` | 보조 텍스트 |
| `--fg-dim` | `#746e5c` | 메타 정보·거터 |

### 문법 강조

| 토큰 | 기본값 | 쓰이는 곳 |
|------|--------|-----------|
| `--syn-keyword` | `#a626a4` | 키워드 |
| `--syn-func` | `#2364f0` | 함수 |
| `--syn-string` | `#3e7c3d` | 문자열 |
| `--syn-type` | `#946501` | 타입·상수 |
| `--syn-comment` | `#6d6e76` | 주석 |
| `--syn-delete` | `#d82f20` | 삭제·에러 |

### 그 외

| 토큰 | 기본값 | 설명 |
|------|--------|------|
| `--radius` | `8px` | 모서리 둥글기 |
| `--measure` | `82ch` | 본문 문단 최대 폭 |
| `--font-sans` | Pretendard | 본문 글꼴 |
| `--font-mono` | JetBrains Mono | 코드·메타 글꼴 |

### 다크 모드도 같이 고쳐야 합니다

같은 이름의 토큰이 `html.dark { ... }` 블록에 한 벌 더 있습니다.
라이트만 고치면 다크에서 어긋납니다.

### 대비를 확인하세요

색을 바꿀 때는 배경 대비 **4.5:1** 을 넘기세요. 기본 팔레트는 본문 배경과
코드 배경 양쪽에서 이 기준을 넘도록 명도를 낮춰 잡은 값입니다. Atom One Light
원색을 그대로 쓰면 회색·노랑 계열이 기준에 걸립니다.

### 글꼴 바꾸기

`--font-sans` / `--font-mono` 를 바꾸고, `skin.html` `<head>` 의 폰트
`<link>` 도 같이 바꿔야 합니다. 지금은 두 스타일시트를 `rel="preload"` 로
받아 `onload` 에서 `rel` 을 바꿔 답니다. 그냥 `rel="stylesheet"` 로 두면
첫 페인트를 막습니다. 교체할 때 이 형태를 유지하세요.

## 7. 안 될 때

### 코드블록에 색이 안 들어옵니다

1. 에디터에서 코드블록 **언어를 지정**했는지 확인하세요. 지정하지 않으면
   highlight.js 가 자동 감지로 떨어져 짧은 스니펫을 엉뚱한 언어로 봅니다.
2. `images/script.js` 가 **`images/` 아래**에 있는지 확인하세요. 루트에
   올리면 `skin.html` 이 못 찾습니다.
3. cdnjs 가 막힌 환경이면 무채색으로 떨어집니다.

### 목차가 안 나옵니다

- `show_toc` 옵션이 켜져 있는지 확인하세요.
- 본문에 `h2`/`h3` 가 **2개 이상** 있어야 합니다.
- 좁은 화면에서는 접힌 상태가 정상입니다. `OUTLINE` 을 누르세요.

### 카테고리 글 수 `(N files)` 가 안 보입니다

[2-3](#2-3-카테고리-글-수-표시) 을 확인하세요. 카테고리 모듈이 숫자를
출력하지 않으면 이 표시도 사라집니다.

### 카테고리 모양이 이상합니다

[2-2](#2-2-카테고리-형식을-리스트형으로) 의 폴더형/리스트형 문제입니다.

### 모바일에서 완전히 다른 디자인이 나옵니다

[2-1](#2-1-모바일-웹-자동-연결-끄기-필수) 입니다. 티스토리 기본 모바일 스킨을
보고 계신 겁니다.

### 스킨 설정에 새 옵션이 안 보입니다

`index.xml` 을 `스킨 등록` 경로로 다시 올렸는지 확인하세요. 스킨 편집기에서는
`index.xml` 을 열 수 없습니다.

### 기본값을 바꿨는데 반영이 안 됩니다

`index.xml` 의 `<default>` 는 스킨을 **처음 적용할 때만** 쓰입니다. 이미
저장된 값은 `스킨 설정` 에서 손으로 바꿔야 합니다.

### 글 제목이 두 번 나옵니다

목록 페이지의 `h1` 과 겹치는 경우입니다. `skin.html` 의 `<body id="...">` 와
`style.css` 의 페이지별 분기를 건드렸다면 되돌리세요.
